# Onam Lucky Draw Website

Frontend for the Onam Lucky Draw registration system.

## Tech Stack

- React
- Vite
- Tailwind CSS
- Framer Motion
- Razorpay Checkout

## Installation

Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/onam-website.git
cd onam-website
```

Install dependencies

```bash
npm install
```

## Environment Variables

Create a `.env` file.

Example:

```env
VITE_API_URL=http://localhost:5000

VITE_RAZORPAY_KEY_ID=your_test_key
```

## Run

```bash
npm run dev
```

Application runs on

```
http://localhost:5173
```

## Features

- User Registration
- Razorpay Payment
- Ticket Generation
- Responsive UI
- Ticket Printing
