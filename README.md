# Onam Lucky Draw Website

Frontend for the Onam Lucky Draw registration system.

## Tech Stack

- React
- Vite
- Tailwind CSS
- Responsive Design

## Installation

Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/onam-website.git
cd onam-website
```

Install dependencies

```bash
npm install
```

## Environment Variables

Create a `.env` file.

Example:

```env
VITE_API_URL=http://localhost:5000/api
VITE_GOOGLE_PAY_URL=https://pay.google.com/... (replace with confidential URL)
```

## Run

```bash
npm run dev
```

Application runs on

```
https://onam-backend-wkz2.onrender.com
```

## Features

- Ticket Generation
- Responsive UI
- Ticket Printing
